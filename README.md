# ai-engineering-course

## Troubleshooting

### timeout или 503 – провайдер недоступен

**Что видел:** запрос зависал и падал по timeout, либо в ответе приходил 503.
**Почему:** провайдер временно недоступен или перегружен, сеть не отвечает вовремя.
**Что сделал:** проверил статус провайдера, добавил повтор с паузой, а когда не помогло - переключился на fallback [HuggingFace], чтобы скрипт не падал.

### ModuleNotFoundError – не активирован .venv или запуск не из той папки

**Что видел:** при запуске скрипта ошибка ModuleNotFoundError - не находится нужный модуль.
**Почему:** не активировано виртуальное окружение .venv или скрипт запускается не из папки проекта.
**Что сделал:** активировал .venv, перешёл в папку проекта и запустил скрипт оттуда; при необходимости доустановил зависимости через pip.
